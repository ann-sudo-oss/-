# 三角岩 · 好友联机预览版

这是可在本地运行的首版联机实现，不是已经部署的公网服务器。

## 启动

需要 Node.js 22 或更新版本，无第三方依赖。在包含游戏文件的目录中执行：

```sh
node server/server.mjs
```

打开 `http://127.0.0.1:8787/`，先注册并登录，再到游戏大厅选择“创建房间”或“单人模式”。单人模式保存到当前浏览器，与联机存档独立；创建房间后，把六位房间码交给朋友。每房间最多 8 位成员，账号首次加入后绑定该房间。模式在首次进入游戏的弹窗中选择并锁定。

Mac 也可以双击发布包内的“启动联机试玩.command”。Windows 可以双击“启动联机试玩.bat”。

## 本机双人测试

第一位玩家打开 `http://127.0.0.1:8787/`，第二位玩家用另一个浏览器或隐私窗口打开同一地址。也可以分别使用 `127.0.0.1` 和 `localhost` 两个地址来隔离登录 Cookie。第二个账号输入第一个账号的房间码，然后点击“拜访基地”。双方进入同一基地后能看见彼此的角色与名字。

游戏右上角“联机”按钮可以拜访、回家、重新加载服务器存档；主人可以在这里授予、收回其他成员的建造与使用箱子权限。

## 局域网试玩（可信朋友）

默认只监听本机。要让同一 Wi-Fi 的其他设备连接，Mac/Linux 使用：

```sh
HOST=0.0.0.0 node server/server.mjs
```

其他设备访问 `http://运行服务器那台电脑的局域网IP:8787/`。保持电脑和服务运行。手机与电脑必须处在能够互访的局域网，系统防火墙也需要允许该连接。此方式仅供可信网络测试，不是公网发布。

## 已实现

- 独立昵称账号、加盐 scrypt 密码哈希、HttpOnly 会话 Cookie。
- 房间码、8 人上限、在线列表、账号与基地绑定。
- 服务器磁盘存档：个人背包、装备、进度与基地建筑、房屋、家具、箱子、农田。
- 房间成员的房屋分布在同一海岛上的不同地块；可以看到彼此房屋和主人名，走近按 E 拜访。房屋楼层、窗台与围栏会跟随存档外观同步。
- 主人 / 协作者 / 只读访客；服务器校验保存权限，访客不会收到箱子内容。
- 协作者的背包仍是自己的，修改基地需要主人的授权。
- SSE 下发角色位置，HTTP 上报移动与保存；室外可以跨个人基地看到其他玩家；进入室内后只显示同一房屋内的玩家。
- 保存版本校验，防止两个页面直接覆盖旧存档；发生冲突时停止覆盖并提示重新载入。
- 房间使用统一的服务器时间与天气；地表坑洞由服务器处理挖掘操作，并通过 SSE / 云端轮询同步。旧存档中的坑洞首次加载时合并，同一区域取较深值。
- 角色收到地形变化后更新碰撞和支撑高度，室外站立角色按共享地面校正。雨雪地面积累根据同一房间的气候记录计算。
- 个人进度默认每 5 秒保存，页面退出前提示尚未完成的保存；断线保留待发送数据并重试。
- 单人原存档仍使用原来的本地键，联机账号不会写入或覆盖它。

## 当前边界

- 本版是好友合作原型。地表挖掘已由服务器统一处理；矿岩、生物、掉落、地下矿井与战斗经济仍主要由客户端模拟，不是统一权威战斗服务器，不能用于有防作弊要求的公开竞技或交易。
- 基地建筑和箱子按快照同步，通常在一次保存后约 5 秒内更新；多人同时改同一基地可能出现版本冲突，需要重新加载，尚未实现逐操作合并。不要同时整理同一箱子。
- 协作者权限同时允许建造及箱子使用，尚未细分为多个授权开关。
- 房屋外观和室外玩家显示在共享岛屿的固定地块上；拜访他人房屋的完整内部设施仍会重新加载场景。当前共享外观包含主体房屋、楼层、窗台与围栏，尚未复制所有自由摆放的小物件。
- 显示其他玩家的位置与朝向；暂未同步武器动作、载具乘客、玩家伤害、交易与语音聊天。
- 此版没有账号找回、邮件验证、踢人或换房间功能。仅适合小范围测试。
- 存档为原子替换的 JSON 文件，单进程运行；不是高并发数据库方案。服务器离线时作物生长时间仍按实际时钟计算，其他世界模拟暂停。

## 保存与备份

默认 `server/data/worlds.json` 保存所有账号、会话和世界。该目录由 `.gitignore` 排除，绝不能上传 GitHub 或放进发布包。测试账号也不会随发布包分发。

停止服务器后备份整个 `server/data` 目录；恢复时停止服务再还原备份。可以通过 `DATA_DIR` 设置独立的永久存储路径。意外崩溃后若有残留 `.lock`，确认旧进程已经停止，再删除 `.lock` 重启；不能同时启动两个进程写同一份存档。

## 未来公网部署

GitHub Pages 只能托管单人静态页面，不能运行本后端。本后端同时提供网页与 API，应整体部署到支持 Node.js、长连接和永久磁盘的主机，通过同一 HTTPS 域名访问。公网部署需要 HTTPS，并设置 `COOKIE_SECURE=1`；反向代理应关闭 SSE 缓冲并允许长连接。不能使用会随重启清空文件的临时目录，也不能直接开多副本共享 JSON 文件。

发布包提供 Dockerfile 与 compose.yaml，便于后续接入托管服务；当前本地版本没有开通付费托管。另有已部署的 Sites 云端版本，采用 ChatGPT 登录和 D1 存档，访问 https://triangle-island-adventure-oct30.munalee1987.chatgpt.site/ 。该云端站点暂保留仅主人可见的访问范围；不是已对所有玩家开放。

## 验证

```sh
node --test server/server.test.mjs
```

覆盖注册登录、房间隔离、个人背包隔离、基地授权和撤销、保存冲突、模式锁定、跨站写入防护、实时位置消息、服务器重启恢复、密码和会话令牌不以明文落盘，以及禁止下载服务器数据文件。

更新到共享世界版本后，所有房间成员都应刷新页面重新进入；旧客户端不会自动切换挖掘协议。联机睡觉恢复生命和体力，暂不单独跳过全房间的夜晚。
